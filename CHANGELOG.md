# Changelog

Each section is the text of that GitHub release. Add the new section before tagging.

## v2.0.8

- numpy and matplotlib are built in.
- Any tab can be closed (X, Ctrl+W or middle click), always after a confirmation. A dot marks unsaved files.
- The built-in Python ignores packages of other Pythons on the computer.

## v2.0.7

- Open File (Ctrl+Shift+O) for single Python files, without a project.
- The folder chosen for new projects is remembered.
- UML shows types for negative values and imported math functions, e.g. `-sqrt(...)`.

## v2.0.6

- pygame-ce replaces pygame. Programs still use `import pygame`.
- Python files open by drag and drop or with *Open with*.
- New BMI template for 2CB.
- The booklet panel is open on first run.
- Fixed a black strip when resizing the side panels.

## v2.0.5

- Package for the Microsoft Store (MSIX).
- Privacy statement and signing policy updated.

## v2.0.4

- Booklet panel without a booklet: download it, drop the PDF, or choose it. The copy also works offline.
- Second download address, and installation help for IT.

## v2.0.3

- EduPython is open source under the MIT License.
- The booklet is downloaded once instead of being part of the program.

## v2.0.2

- Print and Export as PDF, with file path, login name and date on every page.
- Run (F5) always runs the open file.
- List of installed libraries, and a default settings file.
- `--booklet` option for shortcuts; light mode is the default.
- Linux version.

## v2.0.1

- Fixed a crash when opening the Edit menu without a project.
- Clickable links in the booklet.
- School options: hide paths, default project folder, `--config`.
- Crash log.

## v2.0.0

- New native version, written in Rust and renamed to EduPython.
- Live UML class diagram that can also edit the code.
- Booklet viewer with search and text selection.
- School settings in `edupython.ini`.
- File tabs, and the Pong exercise as a template.
